SAINTS GTA 5 RP EASTER EGG HUNTER
========================================

ИНСТРУМЕНТЫ:

1. ПОИСК ПО ИМЕНАМ ФАЙЛОВ:
   python3 ~/gta_hunt/search.py /путь/к/сборке

2. ПОИСК ПО ХЕШАМ:
   python3 ~/gta_hunt/hash_search.py /путь/к/сборке хеш1,хеш2

3. ПОИСК ТЕКСТА В ФАЙЛАХ:
   python3 ~/gta_hunt/string_search.py /путь/к/сборке "пасхалка"

4. ПОИСК ARENA:
   python3 ~/gta_hunt/search.py /путь/к/сборке | grep -i arena

5. ПОИСК CC850:
   python3 ~/gta_hunt/search.py /путь/к/сборке | grep -i cc850
