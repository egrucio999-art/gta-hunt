# GTA V RPF Archive Reverse Engineering Toolkit

Инструментарий для реверс-инжиниринга проприетарных архивов RPF (Rockstar Package File) из игры Grand Theft Auto V.

## Описание
Формат закрытый. Скрипты позволяют распаковывать архивы, искать ассеты по хешам (Jenkins hash) и анализировать структуру.

## Модули
- rpf_extract.py
- rpf_extract_full.py
- hash_search.py
- string_search.py
- search.py
